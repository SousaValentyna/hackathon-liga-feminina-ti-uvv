# 🌟 hackathon-liga-feminina-ti

Repositório oficial do projeto desenvolvido para o **1º Hackathon da Liga Feminina de TI da Universidade de Vila Velha (UVV)**. Este projeto tem como objetivo criar o site oficial da Liga, promovendo a inclusão feminina no setor de tecnologia por meio de uma plataforma acessível, funcional e responsiva.

## 📁 Estrutura Inicial do Projeto

O projeto é baseado em uma arquitetura de página única (Single Page Application), com a seguinte estrutura de diretórios:


hackathon-liga-feminina-ti/
├── index.html # Página única com todas as seções (R1 a R5)
├── css/
│ └── style.css # Estilos globais e responsividade
├── js/
│ ├── main.js # Scripts gerais e interações
│ └── email.js # Lógica para cadastro e validação de e-mails (R3)
├── assets/
│ ├── img/ # Imagens da galeria, logo e ícones
│ └── videos/ # Vídeos da galeria
├── data/
│ ├── membros.json # Dados dos membros da Liga (simulação de base de dados)
│ └── emails.json # Lista de e-mails simulada (se não usar backend)
└── README.md # Documentação do projeto com instruções e capturas de tela


## 📌 Status

## 📅 Hackathon

Este projeto faz parte do **1º Hackathon da Liga Feminina de TI da UVV**, com foco em:

- Representatividade feminina na tecnologia
- Desenvolvimento web acessível
- Aplicação prática de conhecimentos acadêmicos
