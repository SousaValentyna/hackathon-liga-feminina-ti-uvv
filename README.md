<h1 style="color:#8E59D9">🌟 hackathon-liga-feminina-ti</h1>

Repositório oficial do projeto desenvolvido para o  
<strong><span style="color:#59D975">1º Hackathon da Liga Feminina de TI da Universidade de Vila Velha (UVV)</span></strong>.

Este projeto tem como objetivo criar o site oficial da Liga, promovendo a  
<strong><span style="color:#59D975">inclusão feminina no setor de tecnologia</span></strong>  
por meio de uma plataforma acessível, funcional e responsiva.

<br>

<h2 style="color:#8E59D9">📁 Estrutura Inicial do Projeto</h2>

O projeto é baseado em uma arquitetura de página única (Single Page Application), com a seguinte estrutura de diretórios:


hackathon-liga-feminina-ti/ <br>
├── index.html # Página única com todas as seções (R1 a R5) <br>
├── css/ <br>
│ └── style.css # Estilos globais e responsividade <br>
├── js/ <br>
│ ├── main.js # Scripts gerais e interações <br>
│ └── email.js # Lógica para cadastro e validação de e-mails (R3) <br>
├── assets/ <br>
│ ├── img/ # Imagens da galeria, logo e ícones <br>
│ └── videos/ # Vídeos da galeria <br>
├── data/ <br>
│ ├── membros.json # Dados dos membros da Liga (simulação de base de dados) <br>
│ └── emails.json # Lista de e-mails simulada (se não usar backend) <br>
└── README.md # Documentação do projeto com instruções e capturas de tela <br>

<h2 style="color:#8E59D9">📅 Hackathon</h2>

Este projeto faz parte do  
<strong><span style="color:#59D975">1º Hackathon da Liga Feminina de TI da UVV</span></strong>, com foco em:

- <span style="color:#59D975">Representatividade feminina na tecnologia</span>  
- <span style="color:#59D975">Desenvolvimento web acessível</span>  
- <span style="color:#59D975">Aplicação prática de conhecimentos acadêmicos</span>  

<br>
